Ayuda: Formato de Compras (registro rápido)

Usa esta página para registrar compras y actualizar costos del inventario.

  • Proveedor: Selecciona o crea el proveedor antes de agregar artículos.
  • Autocompletar: Escribe el Código y presiona Enter o Tab para autocompletar. Usa el botón Buscar artículo o F2 para búsqueda manual.
  • Añadir fila: El botón Agregar inserta una nueva fila solo si la fila actual es válida.
  • Costos: El valor en Costo se aplicará a la ficha del producto; se mostrará una advertencia si editas costos.

Validaciones clave:

  1. Debe existir proveedor antes de guardar.
  2. Cada artículo necesita código, cantidad > 0 y costo válido.
  3. No se permiten artículos duplicados en la misma compra.
